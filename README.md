# Classic Minesweeper

A retro Windows Minesweeper clone built with **B4X / B4J**.

## 🎮 Features
- 3 difficulty levels: **Beginner**, **Intermediate**, **Expert**.
- Original retro UI, timer (000–999), digital mine counter, and interactive smiley face.
- Sound effects, background music, and best time tracking.
